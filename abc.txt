PS 2: Data Wrangling II1. Explanation of the Problem StatementReal-world data is messy. This assignment focuses on finding and fixing missing values, spotting and treating outliers, and applying mathematical transformations (like log scaling) to fix skewness.2. What We Need to DoScan and handle missing values (imputation with mean/median or dropping).Detect outliers using IQR (Interquartile Range) or Z-score and treat them (capping/trimming).Apply data transformations (e.g., np.log) to reduce skewness.3. How to Perform ItMissing values: df.fillna() or df.dropna().Outliers: Calculate $Q1$, $Q3$, $IQR = Q3 - Q1$, and filter values outside $[Q1 - 1.5 \times IQR, Q3 + 1.5 \times IQR]$.Transformation: Apply np.log() or np.sqrt().4. RequirementsPython with pandas, numpy.5. Codeimport pandas as pd
import numpy as np

df = pd.read_csv("https://raw.githubusercontent.com/mwaskom/seaborn-data/master/titanic.csv")

# 1. Handle missing values
df['age'] = df['age'].fillna(df['age'].median())

# 2. Outlier detection & treatment (using IQR on 'fare')
Q1, Q3 = df['fare'].quantile(0.25), df['fare'].quantile(0.75)
IQR = Q3 - Q1
lower, upper = Q1 - 1.5 * IQR, Q3 + 1.5 * IQR
df['fare'] = np.where(df['fare'] > upper, upper, df['fare']) # Capping outliers

# 3. Data Transformation (Log transform to reduce skewness)
df['log_fare'] = np.log1p(df['fare'])
print(df[['fare', 'log_fare']].head())

PS 11: Distributed Application using MapReduce (Log Processing)1. Explanation of the Problem StatementMapReduce is a programming model for processing large data sets with a parallel, distributed algorithm on a cluster. Here, we write a Python-based MapReduce simulator to process and aggregate system logs (e.g., counting log levels like INFO, ERROR, WARN).2. What We Need to DoSimulate a Map function that extracts key-value pairs (e.g., (log_level, 1)).Simulate a Reduce function that aggregates counts per log level.3. How to Perform ItUse Python dictionaries or itertools.groupby to simulate the Map and Reduce phases.4. RequirementsPython (Standard library).5. Codefrom collections import defaultdict

# Sample system logs
logs = [
    "INFO: Server started successfully",
    "ERROR: Database connection failed",
    "INFO: User logged in",
    "WARN: High memory usage",
    "ERROR: Timeout occurred"
]

# Mapper function: emits (log_level, 1)
def mapper(log_lines):
    mapped_data = []
    for line in log_lines:
        level = line.split(':')[0]
        mapped_data.append((level, 1))
    return mapped_data

# Shuffle & Sort step
def shuffle(mapped_data):
    shuffled = defaultdict(list)
    for k, v in mapped_data:
        shuffled[k].append(v)
    return shuffled

# Reducer function: sums counts per log level
def reducer(shuffled_data):
    reduced_output = {}
    for k, values in shuffled_data.items():
        reduced_output[k] = sum(values)
    return reduced_output

# Execution
mapped = mapper(logs)
shuffled = shuffle(mapped)
result = reducer(shuffled)

print("Log Analysis Result (MapReduce Simulation):", result)

Codeimport org.apache.spark.sql.SparkSession

object SparkLogProcessor {
  def main(args: Array[String]): Unit = {
    // Initialize Spark Session
    val spark = SparkSession.builder()
      .appName("Simple Log Processor")
      .master("local[*]")
      .getOrCreate()

    import spark.implicits._

    // Sample log data
    val logData = Seq(
      "INFO System up",
      "ERROR Disk full",
      "INFO User connected",
      "ERROR Out of memory"
    )

    val rdd = spark.sparkContext.parallelize(logData)

    // Filter error logs and count
    val errorCount = rdd.filter(line => line.contains("ERROR")).count()
    
    println(s"Total Error Logs: $errorCount")

    spark.stop()
  }
}
